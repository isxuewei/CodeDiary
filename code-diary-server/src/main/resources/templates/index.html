通过 AI 生成 Git 提交日志和工作报告

CodeDiary 直接工作在 IntelliJ IDEA 里：先读取已选代码变更，生成符合项目习惯的提交日志；再把真实 Git 提交整理成清晰的工作日报。少切换工具，把时间留给代码。

围绕 Git 的两条日常工作流

写完代码后，CodeDiary 接住最容易打断思路的两件小事：先说明这次改了什么，再整理今天做了什么。

代码变更 → Commit Message

从代码差异生成提交日志

在 Commit 面板勾选本次变更，CodeDiary 会结合文件清单、代码差异和最近提交风格，生成提交日志并回填输入框。

提交记录 → 工作日报

从真实提交生成日报

读取所选提交的完整信息，按项目分别交给 AI 总结。技术改动会被整理成清晰、可编辑的工作内容，生成后可直接复制。

多仓库

一个项目里的仓库一起整理

自动扫描项目目录及子目录中的 Git 仓库，可查看全部仓库，也可单独筛选。跨仓库提交会按项目分别生成日报。

时间与提交筛选

只选真正需要汇报的内容

支持今天、昨天、近一周、近一月和自定义日期范围，并按当前 Git 用户读取提交。列表可全选、逐条勾选，悬停还能核对完整详情。

个性化格式

让输出适应你的团队

日报模板、Git 日志格式和语言风格要求都可以自行配置。设置保存在 IDE 本地，后续生成会继续沿用。

IDE 内完成

不离开编码现场

日报入口位于 CodeDiary 工具窗口，提交日志入口就在 Commit 面板。查询、筛选、生成、编辑和复制都能在 IntelliJ IDEA 内完成。

安装使用

安装插件后，在右侧工具窗口打开 CodeDiary 即可开始。

IDEA 插件市场安装（推荐）

打开 IntelliJ IDEA → Settings/Preferences → Plugins → 搜索 "CodeDiary" → 点击 Install 安装 → 重启 IDE

手动安装

访问 JetBrains Marketplace 下载最新版本 → Settings/Preferences → Plugins → ⚙️ → Install Plugin from Disk → 选择下载的文件

生成 Git 提交日志

在 Commit 面板勾选代码变更 → 点击 CodeDiary 图标 → 等待生成结果自动回填提交消息输入框

生成工作日报

点击工具栏 CodeDiary 图标 → 选择时间范围和提交记录 → 点击生成 → 复制粘贴到汇报系统
